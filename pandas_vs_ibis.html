Ibis is a newer framework that uses duckdb as a backend by default, and its API is a mix between duckdb and dplyr.

Code 
import ibis
from ibis import _

ibis.options.interactive = True

import pandas as pd

_ in Ibis is a special variable that refers to the last expression evaluated. This is useful for chaining operations or for using the result of the last expression in subsequet operations. By default, ibis defers execution until you call execute() (much like dask). Using the above code ibis.options.interactive = True makes it so that expressions are immediately executed when displayed. As the text implies, its useful for interactive exploration.
